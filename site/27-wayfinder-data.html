§3 การปกปิด PII — ทำงานที่ไหน และช่องว่างตรงไหน

ประเภทวิธีตรวจ
เลขบัตร ปชช./คนต่างด้าว 13 หลักคำนวณ checksum จริง (ไม่ใช่จับทุกเลข 13 หลัก)
บัตรเครดิตตรวจ Luhn จริง
เบอร์ไทย / อีเมลregex
query/JSON key อ่อนไหวรายชื่อ ~30 คำ (password, token, api_key, citizen_id, cvv, ...)
Authorization headerregex — mask ทั้ง Bearer และ Basic
ปกปิดที่ edge ก่อนออกจากเครื่อง — แต่มีเส้นทางเลี่ยงอยู่จริง

PII masking อยู่บนเส้นทาง edge→main และ endpoint แสดงผลเท่านั้น — log_forward ที่อ่านไฟล์บน Main โดยตรง (เส้นทางที่ทำงานจริงตอนนี้) ไม่ผ่าน masker เก็บ raw ทั้งก้อนลง DynamoDB รวม request body และ header ที่ ModSecurity บันทึกไว้

§5 Dependency ภายนอก — ถ้าหายไปแล้วใครเจ็บ

§7 ความลับที่พบว่าเก็บไม่ปลอดภัย (ไม่แสดงค่าใดๆ)
