# Docs for WAF Project

เว็บรวบรวมเอกสารและความเข้าใจระบบ WAF ที่ดูแลอยู่ — architecture, config, และ traffic flow

Build ด้วย [Docusaurus](https://docusaurus.io/), deploy อัตโนมัติขึ้น GitHub Pages ผ่าน GitHub Actions ทุกครั้งที่ push เข้า `main`

เว็บ: https://jakkaret.github.io/Docs-for-WAF-project/

## Local development

```bash
npm install
npm start
```

## Build

```bash
npm run build
```
